# مولد تقارير تسليم الحيازات الزراعية

برنامج Windows بواجهة رسومية يقرأ ملف Excel النهائي للجمعية، يحسب إحصائيات التسليم، ثم يقرأ بيانات الجمعية والإحصائيات من ملف Excel، ثم يملأ قالب Word المعتمد ويحفظ تقريرًا جديدًا باسم الجمعية.

## التثبيت والتشغيل

1. فك ضغط المشروع داخل:

   `D:\WORK\python_projects\hiyaza_report_gen`

2. تأكد من تثبيت Python 3.11 أو أحدث وتفعيل خيار `Add Python to PATH`.
3. شغّل الملف `run_app.bat`.
4. في أول تشغيل سينشئ البرنامج بيئة افتراضية ويثبت المكتبات المطلوبة تلقائيًا.

## طريقة الاستخدام

1. اضغط **استعراض** واختر ملف Excel.
2. القالب الافتراضي موجود داخل `assets`، ويمكن اختيار قالب Word آخر عند الحاجة.
3. اضغط **تحليل ملف Excel**.
4. راجع اسم الجمعية والنوع والإحصائيات.
5. يتم استخراج **كود الجمعية** تلقائيًا من عمود «كود الجمعية» داخل ملف Excel.
6. عدّل تاريخ التسليم أو الملاحظات الخاصة عند الحاجة.
7. اضغط **إنشاء تقرير Word**.
8. اختر مكان واسم حفظ التقرير من نافذة Save As.

## قواعد الحساب

تُعتبر القطعة مسجلة على المنظومة عند تحقق الشروط التالية:

- كود القطعة موجود.
- رقم الحيازة موجود وليس فارغًا أو `0` أو `-1`.
- اسم الحائز موجود.
- الرقم القومي مكوّن من 14 رقمًا وليس `11111111111111`.

القطع غير المحيزة جزء من القطع غير المسجلة ولا تُضاف إليها مرة أخرى.

## القالب الافتراضي

المسار:

`assets\DST_Agricultural_Association_Report_Template.docx`

يستطيع البرنامج استخدام Template آخر إذا احتفظ بنفس العناوين الأساسية داخل الجداول.

## إنشاء EXE

بعد تجربة البرنامج بنجاح، شغّل:

`build_exe.bat`

وسيظهر البرنامج داخل:

`dist\HiyazaReportGenerator\HiyazaReportGenerator.exe`
